# Draw Now 绘画应用开发计划
# Draw Now Painting Application Development Plan

## 项目背景
## Project Background

当我在appstore寻找一个简单的绘画app时,很难找到一款超级简单的绘画app,所以我决定自己开发一个.
这里它需要做到两件事
1. 提供一个足够简单的绘画板,简单到4岁的儿童都能随意绘画
2. 提供情绪价值,帮助哪些抑郁症患者通过绘画来填满自己荒芜的思想,从而抵抗抑郁症

When I was looking for a simple drawing app in the App Store, it was difficult to find an extremely simple drawing app, so I decided to develop one myself.
This app needs to accomplish two things:
1. Provide a drawing board simple enough for even a 4-year-old child to draw freely
2. Provide emotional value, helping depression patients fill their barren thoughts through drawing, thereby fighting depression

## 设计理念
## Design Philosophy

- **艺术创造力**：提供工具让用户表达内心世界，释放压力，找回内心平静与活力
- **抵制荒芜思想**：通过绘画创作，帮助用户重新连接内心，培养积极健康的心态
- **艺术疗愈**：利用艺术创作的治愈力量，帮助缓解抑郁、焦虑等情绪问题
