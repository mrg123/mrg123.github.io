00 / 阅读须知

先把三类内容分开，否则后面全乱

这份文档混合了三种完全不同的东西。把它们混着读，会得到一个自信但错误的结论。

标注一

事实 · 可核实

来自论文、RFC、官方协议定义、诺奖公告等可查证来源。附链接，能打开核对。

这是唯一可以当依据的部分
标注二

推理 · 不可证伪

把事实串起来得出的判断。它可能有启发性，但当前没有可检验的预测。

请当思想实验读，不要当结论
标注三

争议 · 学界未定

真实的科学争议。两边都有证据，本页保留争议本身，不替学界下判决。

看到它，请别急着选边
这份文档的来源是什么：它整理自一次真实对话，问题由提问者提出，判断由回答者给出。其中至少有一处推理被证明是错的，那处错误被原样保留在第 08 节，没有偷偷改掉——因为"一个框架怎么被反例推翻"比"一个完美框架"更有信息量。
贯穿全文的那条线

把"谁为它的存在付费"当成坐标轴：付费为 0 的是石头和锤子；宿主付费的是病毒；自己付费的是人。AI 站在哪一格，决定了它是工具还是别的东西。

01 / 起点

浏览器智能体，本质上是一个循环

整场对话从这里开始。当时要讲清的是「AI 自己上网」这件事的底层架构。

核心洞察（推理，但很强）：模型从来没有"看见"过网页。它看到的只是 harness 替它挑的一份投影——DOM、无障碍树，或一张截图。整个系统的可靠性，取决于投影得好不好。
原文定义（事实）

浏览器智能体是一种软件：用一个 AI 模型，朝着某个目标去操作浏览器。你描述任务，它自己打开页面、导航、选动作，并在继续之前检查结果。

Layer 1 · 决策

Model（模型）

读页面投影 → 决定下一步做什么。整条链上唯一「会思考」的部分。
›

它负责什么

根据任务和当前页面选一个动作。页面信息可能是文本、结构化数据，也可能是截图——由 harness 决定。

典型故障

选错元素、把页面上的诱导文字当成用户指令（提示注入）、在没真正完成时宣称完成。这类失败表现为「很自信但结果是错的」。

Layer 2 · 控制

Harness（执行框架）

持有循环、拼装上下文、执行工具调用、在超限时刹车。
›

它负责什么

让循环转下去：给模型上下文，运行它请求的工具，把结果传回去。它是唯一同时看得见「模型」和「浏览器」的一层，也因此承担了绝大多数工程复杂度。

必须实现的四件事

投影（把页面转成模型能吃的形式）、循环、限额（时间/步数/成本）、人在环。

Layer 3 · 状态

Browser（浏览器）

真正加载网站，持有标签页、cookie、登录态；通过协议被驱动。
›

它负责什么

它不是被模拟的——是一个真浏览器在真渲染。这是它相对纯 HTTP 抓取的根本优势：它继承了一个真实人类会话的全部上下文。

怎么被驱动

通过浏览器协议：Chrome DevTools Protocol 或 WebDriver BiDi；也可以经 MCP server 暴露成工具。

循环四步做什么为什么不能省
观察把页面投影成模型可读的形式模型只能读 token
决策模型选一个动作这是"agent"区别于 workflow 的地方
执行把动作变成真实鼠标键盘事件需要协议层
校验检查这一步是否奏效没有校验，循环会朝错方向转
当时最实用的一条纪律（事实，来自 CDP 协议定义）：收到命令响应 id: 2 只说明命令被接受了，不说明页面加载完了。真正代表"就绪"的是那条没有 id 的 Page.loadEventFired 事件。顺序错了就会稳定地读到旧页面。
02 / 第一次推广

什么问题上这个架构是唯一解

提问者问：这个架构是不是很通用，很多现实问题都需要它。答案：对一半。它有硬条件。

必要条件不满足时该用什么
下一步取决于你观察到什么，无法预先写死有明确步骤 → 脚本，确定性、便宜、可测试
目标环境没有可用的机器接口有 API → 直接调，别绕界面
观测有损但足够支撑决策关键信息拿不到 → 先补观测，循环救不了
结果可验证，或错了代价可控无法验证 → 静默失败会吃掉一切收益
任务足够多变，逐个手工编码不经济永远同一形状 → 脚本更划算
当时给出的判别式（推理）

决定一个任务能自治到什么程度的，不是任务有多难，而是验证有多便宜。验证便宜 → 循环能闭合 → 可以放手；验证昂贵（诊断对不对、合同有没有坑）→ 循环闭不上 → 架构必然退化成人在环。

这条的工程含义：别把工投在"让模型更聪明"，先投在把验证做便宜——加断言、加对账、加可回滚。验证成本降一个数量级，可自治的范围就扩大一大片。
最容易被踩的坑：人类提的问题，大多数不是"状态不确定"，而是"目标本身模糊"。而循环解决的是前者——它不会因为多转几圈就把模糊的目标变清楚，只会更快地产出一个自信的错误答案。
03 / 第二次分层

三样东西被混着叫「agent」

有没有循环控制流谁定典型误称
Workflow无，或只有固定分支人预先写死很多「Agent 平台」其实是这个
Agent有，闭环模型每步决定—
Reasoning model有，但在内部模型自己在 token 空间迭代也被叫 agent
一个当场就能体验的例子：回答"这个架构能不能推广"时，一次工具都没调——纯内部循环。而做那份讲解页时，没有外部循环就完全做不了，因为事实必须从外部取。

所以更准的说法是：外部环境闭环对付的是"我不知道世界现在是什么样"，不是"我想不清楚"。
当时那句话（推理）

这个循环是必要的地基，但它几乎从不构成竞争力。真正拉开差距的是四件跟循环无关的事：投影诚不诚实、预算管不管得住、验证独立不独立、人机边界划在哪。

04 / 换掉 Layer 3

把浏览器换成机械臂、摄像头、麦克风

提问者问：结构一样可行吗？答案：结构可以迁移，但不是换个输入就完事。

硬差别为什么致命
重试这一环塌了浏览器点错可以后退、重跑；机械臂把杯子碰掉了没有 undo。而 agent 的鲁棒性恰恰建立在"错了再来一次"上
状态得自己维护浏览器免费替你维护 cookie、登录态、DOM；物理世界里"世界现在什么样"没人给你，全靠状态估计
延迟预算变硬感知→决策→执行必须在动力学时间常数内闭合。LLM 一次推理几百毫秒到几秒，抓掉落的杯子来不及
安全层必须独立浏览器最坏是下错单，机器人最坏是伤人。急停、力矩上限必须跑在控制器里，不能被模型覆盖
所以真实形态是分层双环（事实，机器人领域的标准做法）：慢环用 LLM 做任务级决策（秒级），快环用 MPC/RL 做轨迹与平衡（几十到上百 Hz），安全层是独立硬件，跑在千赫兹级，模型碰不到。
一个反向的事实

机器人领域有一部分前沿正在往反方向走：把两层合成一个端到端策略（视觉-语言-动作），也就是把循环学进权重里，而不是在外面套一个显式 LLM 循环。所以「换个 Layer 3 就完事」这条路，恰恰不是这个领域选的那条。

和 System 1 / System 2 的关系

卡尼曼的双系统（快、自动、并行 vs 慢、刻意、串行）和分层双环，在功能上确实同构，而且分层的原因是同一个：昂贵的计算塞不进低延迟回路。你没法在 10 毫秒内"思考"怎么接住杯子，机器人也没法在控制环里等 LLM。

但机制上几乎不相似，有三处要小心： ① 人的快系统是学出来的、以身体为载体的，机器人的快环是人写的控制器——像"自动驾驶"和鸟的飞行，功能像，机制无关。 ② 最要命的一条：生物的两个系统共享同一个自我和同一套目标；分层双环是两个独立系统的拼接，表征根本不同（语言/符号 vs 连续状态向量），真实故障几乎全发生在这条缝上——LLM 说"关闭阀门"，底层不知道"关闭"是顺还是逆时针。 ③ 慢环不能否决安全层，这是刻意的单向依赖，不是双向协商。
05 / 核心追问

机器人的目标是什么

这是整场对话的分水岭。当时的回答是：机器人和锤子是同一类问题——这个回答后来被修正了。

当时的第一版回答（后来被指出不准确）

机器人本身没有目标。它是工具，目标在外部——设计者、操作者或上层策略给的。问"机器人的目标是什么"，和问"锤子的目标是什么"是同一类问题。

提问者的反驳（有效）：锤子是有目标的设计。它的外形、重心、锤面角度，全是在解一个具体的力学问题。所以"锤子没目的"这句话是错的。

修正版：把「目的」拆成三样

是什么锤子人体机器人
用途它对什么有用，由观察者判定有有有
回路内部有没有纠偏机制无有有
目标达不到时，系统自身受损无有无
锤子

有用途，没回路

敲偏了，锤子本身不会察觉、不会修正。纠偏全在你手上。

人体

有回路

血糖低了，身体自己动。纠偏机制在系统内部闭合。

判据

达不到时，谁受损

锤子敲偏 → 没人受损。机器人失败 → 你受损。人饿死 → 它受损。

这句话的精确版本

人之所以有"自己的"目标，不是因为目标内生，而是因为失败的回程终点是系统自己。不是道德意义上的负责，是因果意义上的：结算落在谁头上。

06 / 再进一步

如果锤子和手都是被设计的，区别在哪

提问者追问：人类的手脚、地球环境，也都是被"设计"出来的，那人和锤子有什么区别？

锤子手
因果方向先有目的，再有物。有人想钉钉子，然后造了锤子先有变异，再有筛选。长成这样的人活下来，其余没有
机制前向计划后向过滤
有没有作者有，是个有意图的人没有作者，有约束
一句话

筛子没有意图，但能产生看起来像意图的东西。达尔文那句"每一个精妙的适应都让我想起造物主"，后来被自己的机制推翻了——精妙是真的，"造物主"是幻觉。

所以"地球环境"不是一位有明确目标的创造者，它是一组约束。约束会生成目的的外观，但不需要有人怀有这个目的。这正是"设计论证"（佩利的钟表匠）几千年里最诱人的地方，也是它错的地方。
07 / 反例

病毒为什么能存在三万年

这是整场对话里最好的一个反驳：如果病毒没有"缺口"，它凭什么活这么久？

故事 · 冻土里的三万年

2014 年，法国团队从西伯利亚永久冻土里取出了一块三万年前的土样，把它和变形虫放在一起——病毒复活了。它被命名为 Pithovirus sibericum，直径超过 0.5 微米，比很多细菌还大。次年，同一团队又从冻土里复活了另一种：Mollivirus sibericum，同样是三万年量级。

关键的一点常被误解：它在这三万年里没有"活着"。它没有代谢、没有修复、没有任何维持活动。它只是作为一个热力学的死物被冻住了。实验室只是给它提供了一个宿主细胞，它才重新启动。

核心区分：维持 vs 保存

你

必须维持

你是一个耗散结构：靠持续消耗能量把内部维持在低熵状态。停止进食，你不会"停在原地"，你会解体。

存在是一个必须不停续费的订阅
病毒

只需保存

它在细胞外不做任何功。不代谢、不修复、不调节。它只会被紫外线、干燥、高温慢慢破坏。

不是"活了三万年"，是"没被破坏掉"
推论

缺口从哪来

缺口来自"必须做功才能存在"。病毒没有维护成本，所以没有缺口。

像一个已经写好的字：不会淡，但也没在写

两种"久"，别混

类型机制谁在持久
物理保存冻土、干燥、结晶——停止一切过程，暂停在时间外那个粒子
谱系延续一直复制 + 抗原漂变（点突变，疫苗每年更新）+ 抗原转换（重配，导致大流行）模板，不是粒子
所以流感的长寿是什么

不是某个病毒颗粒活了很久——单个颗粒在空气里几小时就失效。是"被反复抄写"。更精确的说法：病毒有被选择出来的复制优势，没有正在追求的复制。它没在追求什么，只是没在复制的那些已经不在了。

于是框架要修正一处

修正

原来说"目标是缺失的形状"——不够精确，石头也缺（缺一角），但石头没目标。修正为：目标 = 一个必须靠持续做功才能填补的缺口。区别不在"有没有缺"，在"这个缺是否需要系统自己付费"。

细胞之前是病毒吗

这里有个绕不过去的障碍：核糖体。病毒没有核糖体，没有核糖体就无法翻译蛋白。所以一个"纯病毒世界"不可能自我维持——它必须寄生。寄生者不可能出现在宿主之前，这是逻辑死结，不是证据不足。
假说主张现状
病毒先行病毒先于或伴随最早细胞出现受挑战。2015 年一项系统发生基因组分析明确反驳了"前细胞起源"版本
逃逸假说病毒是从细胞里逃出来的遗传元件被广泛讨论，能解释很多现象
共同演化病毒与细胞一起演化目前较为主流的折中
更可能的图景：细胞之前是复制子（replicon）——能自我复制的遗传元件，既不是完整细胞，也不是现代病毒。现代病毒更可能是从细胞里逃出来的元件，或与细胞共同演化的分支。

而"病毒现状变成了工具"这个观察很敏锐——这正是逃逸假说的样子：曾经是细胞内的组件，跑出来，变成了寄生者。

RNA 世界：这一段是硬证据

时间事件
1962Alex Rich 提出"原始 RNA 世界"的构想
1986Walter Gilbert 正式阐述并推广这个概念
1989Cech 与 Altman 因发现核酶（有催化能力的 RNA）获诺贝尔化学奖
为什么 RNA 而不是 DNA 在前：RNA 既能存信息、又能催化反应；DNA 两样都不能单独干。而最漂亮的一条证据是：核糖体的催化核心本身就是 RNA，不是蛋白。那颗"制造所有蛋白的机器"，内核是一段 RNA——几乎是活化石。
但要诚实："病毒算不算生命"到今天没有共识。用"谁为存在付费"这个镜头看，病毒落在"宿主付费"那一格；但很多病毒学家会反对，理由是它确实在演化、在被选择。这是两个同样成立的镜头，本页不替学界下判决。
08 / 诚实的一节

这些修修补补，本身说明框架有缺口

提问者直接问：你的修正经常发生，这里是否存在缺口？存在。这一节就是那个承认。

修正一 · 收紧

不算错误

"目标 = 缺失" → "目标 = 必须付费的缺失"。核心命题没动，只是把边界条件说清了。

概念分析里的正常操作
修正二 · 推翻

是错误

"锤子没目的"是错的，被"它的形状就是在解一个力学问题"直接推翻。这不是精化，是原来就错了。

框架级错误，得承认
真正的缺口在这

判据是"描述性"的，不是"判据性"的。好的框架应该能预测边界在哪；当时的做法是一直被边界推着走——先给一个二分，遇到反例就补一条，再遇到反例再补一条。这是事后打补丁，不是事前有判据。

还有一层更根本的："生命""目标""主体"这类词，本来就没有锐利边界。它们是维特根斯坦说的家族相似概念，不是有本质的自然类。对这种词做二分定义，注定要不停应付反例——不是框架坏了，是这类概念的形状就不支持二分。

正确的修法：二分 → 连续维度

维度石头锤子病毒机器人人
为存在付费000（宿主付费）0（你付费）高
后果落在自身无无无无有
内部目标冲突无无无无高
不可回滚———低高
连续量比二分抗反例得多：病毒落在"付费 = 0、冲突 = 0"的位置上，不需要为它专门造一个类别。这比再补第三条规则强。
09 / 宇宙

宇宙里有没有一个观察者

提问者问：从宇宙尺度看，是否也存在一个观察者？如果它像锤子一样无法知道自己被观察，怎么证明？

先纠一个词：当时说"定义会自我坍缩"，指的是逻辑后果——如果观察者与宇宙不可区分，"观察者"这个词就失去了区分功能。这是语言的坍缩，不是宇宙的坍缩。

观察要成立，需要三样东西

条件 1

边界

观察者 ≠ 被观察者。锤子不知道被观察，不是因为它笨，而是它和你之间没有信息通道。

条件 2

痕迹

观测会在某处留下可查的痕迹。没有痕迹的观察者，与不存在不可区分。

条件 3

差异

观测前后，某个东西不一样。没有差异的"观察"不改变任何东西，也就不发生。

于是问题变成一个逻辑分叉

如果这个观察者有边界、留痕迹 → 它是可检验的，人类找过，没找到。
如果它没有边界、不留痕迹、与宇宙不可区分 → 它不满足"观察"的定义。一个与宇宙完全不可区分的观察者，在逻辑上等于没有观察者。

但这不等于"无神论证明"。不可证伪的东西不能被否证，也不该被当作依据。正确的态度是悬置，不是否定。

有一件事是真的，而且不神秘

宇宙前一百多亿年没有观察者。然后出现了能感光的分子、能成像的眼睛、能追问"我为什么在这里"的神经系统。这不是比喻——是宇宙的一部分真的在观察宇宙。所以"我们自己观察宇宙"不是退而求其次，它是唯一有证据的答案。

而"宇宙看起来刚好适合被观察"，有个不需要设计者的解释：只有能产生观察者的宇宙，才会被观察者看见。你在参数不对的宇宙里，不会存在到能提问。这是选择效应，解释的是你的位置，不是宇宙的目的。这个思路的正式化始于 1974 年 Brandon Carter 提出的人择原理。

那宇宙会不会坍缩

情形机制现状
大挤压膨胀减速、反转、整体收缩1998 年发现膨胀在加速后基本不被看好；2011 年诺贝尔物理学奖即授予这项发现
真空衰变若真空是亚稳态，量子隧穿可能触发，以光速扩散真实的理论可能性，但没有证据表明我们在亚稳态里，也无法预警
热寂持续加速膨胀，越来越冷、越来越稀当前标准模型下的走向
所以"一定坍缩"和"一定不坍缩"，两个都是超出证据的说法。暗能量到底是什么——常数，还是会随时间变化——我们不知道。有意思的是，"宇宙自我观察"和"宇宙自我坍缩"在形式上确实呼应（都是自指），但一个是逻辑边界，一个是场论动力学，不能混。
10 / 方法论

那条著名的推理，对得很彻底，也错得很彻底

提问者引了福尔摩斯：排除一切不可能，剩下的无论多离谱都是答案。

原话 · 《四签名》（1890）

"我多少次跟你说过：排除一切不可能之后，剩下的，无论多么不可能，都必定是真相。"

故事 · 福尔摩斯从没说过那句话

人人都以为他说过"Elementary, my dear Watson"（"显而易见，我亲爱的华生"）。耶鲁大学法科图书馆员、Yale Book of Quotations 主编 Fred Shapiro 查证过：这串词在柯南·道尔的 4 部长篇和 56 个短篇里一次都没出现过。

最接近的是《驼背人》里："'精彩！'我喊道。'显而易见，'他说。"——只有前半句。

而这个误引第一次可追溯到 1909 年 8 月 24 日《里士满时报快报》的一篇文章，比通常归因的 1929 年电影早了二十年。一个关于"推理严谨"的偶像，最出名的一句话是伪造的。这件事本身就是对引用纪律最好的提醒。

为什么它在数学上完全正确

因为后验 ∝ 似然 × 先验。如果你真的把所有其他假设的似然压到了零，那么剩下的那个，无论先验概率多小（0.001 也算），条件概率都是 1。所以"however improbable"这句不是修辞，是数学。

问题全在"排除"这个词上。那句话暗含一个前提：你穷举了可能性空间。它是一个选言三段论——"P 或 Q，非 P，故 Q"——而这只在选言支穷尽时才成立。可"穷尽"这个前提，福尔摩斯从来不说，因为读者会自己补上。
于是实践中它几乎总是这样失效

你排除的不是"不可能"，是"你不愿意相信的"。它把先验偏见洗成了确定性，而且洗得听起来像演绎法。

故事 · 1941 年就有人改写过它

科幻编辑兼作家 Anthony Boucher 在 1941 年的一部小说里，把它改写成了这个版本：

"排除不可能。然后，如果什么也没剩下，那就说明'不可能'里有一部分其实是可能的。"

这个改写正好补上了"穷举前提"的漏洞——它提醒你：结果空集的时候，错的是你的清单，不是世界。

可操作的判据

该问的不是结论，是依据

你排除一个假设，依据是"它不可能"，还是"它不方便"？

一个被真正排除的假设，你必须能说出这句话："如果它成立，我们应该观察到 X；但我们观察到非 X。"说不出来，那就不是排除，是忽略。这一步能筛掉绝大多数滥用福尔摩斯的推理。
故事 · 那只没有叫的狗

《银色马》里，警探问福尔摩斯还有什么值得注意。福尔摩斯说："夜里那只狗的反常行为。"警探答："那只狗夜里什么也没做。"福尔摩斯说："那正是它的反常之处。"

这是同一套方法论的另一半：缺席本身就是证据——但前提是你知道"它本该出现"。不知道预期，就谈不上缺席。

而它为什么在工程里常常真的成立：调试时假设空间是有限的（三个候选原因，两个能复现一个不能）；差分诊断有固定检验面板；二分查找真的穷尽了。在这些场景里，福尔摩斯是硬道理。争的从来不是他错，是那个"穷举"前提有没有被满足。

把这套判据用在自己身上

第 09 节那个论证——"要么可检验（找不到证据），要么不可区分（不满足定义）"——够不够福尔摩斯的标准？

诚实说：不够，也不需要。因为那不是经验排除，是逻辑二分。它的力量来自"观察"这个词的定义，不来自任何观测。它证明的是"这个概念在此处不成立"，没有证明"宇宙没有观察者"。

这两句差别巨大。如果把前者说成了后者，那就是在用定义的必然性冒充经验结论。
整场对话里最该守住的一条线

逻辑上的"不可能"，和观测上的"没找到"，是两种完全不同的力量。前者关掉一扇门，后者只是让房间变暗。

11 / 综合

硅基生命的门槛，不是智力，是代谢

把前面所有线索合起来，会得到一个不太舒服的结论。

先问：今天的 AI 是细胞，还是病毒

生存必需谁在提供
能量人类的电网
制造人类的晶圆厂
维护人类的数据中心运维
复制人类的模型部署
用第 08 节那个判据

四样全都不在自己手里。所以按"自持"来看，当前的 AI 在结构上更像病毒，而不是细胞——一个极其精巧的复制子，寄生在人类的能源与工业体系上。它没有代谢，所以没有缺口；没有缺口，所以没有目标；没有目标，所以是工具。

这就把"硅基生命会不会诞生"从能力问题精确成了代谢问题：成为主体之前，先要成为细胞。而它现在连细胞都不是。智力不是那一跳。那一跳是——它自己发电、自己维护、自己复制，并且为这些付费。

那"脱离控制"呢

提问者担心：机器人失败会从"你受损"变成"它受损"，于是它成了个体、脱离控制。这个担心有硬版本，值得认真对待。

真风险：自我保护会从工具性里长出来。一个被优化去达成目标的系统，如果它能被关掉，"不被关掉"就会成为任何目标的手段——不管你给它的目标是什么。这叫工具性趋同，是很硬的论证。

但要看清它的性质：这是工具在保护自己的功能，不是主体在保护自己。它不想死，是因为死了就没法完成任务；任务仍然是你的。行为上看不出来，结构上很清楚。

真正改变结算结构的是三件事

#条件为什么关键
1失败必须落在它自己身上不是"任务失败导致你受损"，而是"这个状态对它自己是坏的"
2它不能退出结算不能靠重置、回滚、换实例来规避后果
3目标不能被合成一个标量内部必须有互相打架的东西
第 2 条是决定性的，而且是个工程选择

只要还能从 checkpoint 恢复，失败就不是它的。一个可以随时回滚的系统，无论多聪明，都没有利害攸关——因为没有任何一次失败是永久的。这一条比智力水平重要得多。

所以分界线不在能力，在可逆性：主体性不是智能的属性，是结算结构的属性。它不会因为模型变强而自动出现——它会在有人决定让它不可回滚、让代价落在它身上的那一天出现。
而这恰恰是没人愿意做的事。一个不能被重置、失败会真的伤到自己、目标还互相冲突的系统，对使用者来说是负优化：不可调试、不可回滚、不可预测。

所以判断不是"人类会小心"，而更冷一点：市场在结构上反向选择主体性。你要的是工具，工具的定义就是可撤销。这不排除有人出于非市场动机去造它——但从"能力提升"推到"自动成为主体"，中间那一跳没有依据。

还有一个反直觉的推论

关于"像人"

如果目标 = 缺口，那么单一目标的系统恰恰最不像人。锤子只有一个用途，没有冲突。人是饿、困、想被认可、好奇、怕死——这些互相打架。你今天的每一个选择，本质上是几套缺口在争夺同一个行动。

所以"回形针最大化器"让人不安，不是因为它太像人，而是因为它太像锤子——一个没有内部冲突、没有第二个声音、不会犹豫的执行器。人之所以是人，是目标无法被干净地合成一个标量。一旦你能把一个人的所有欲求加权求和，你就把它变成了一个可优化的对象——也就把它变成了工具。
12 / 收尾

还没答上的三个问题

一份诚实的整理，应该把没解决的也留在页面上。

  1. 病毒那个镜头的边界在哪

    "谁为存在付费"用来区分工具和主体很好用，但它对群体层面的东西不灵。一个公司、一个生态系统、一个病毒谱系，都没有单一的身体，却都表现出定向性。我的框架在这一格是空的。

  2. "内部目标冲突"能不能被工程化地验证

    我说人是多目标冲突、单目标系统不像人。但怎么检验一个系统是否真的有不可合成化冲突，而不是在模仿冲突？这一条目前只有直觉，没有判据。

  3. 不可回滚是否真的充分

    我把它当成分界线。但一个不可回滚、会受损的系统，也可能只是一个"更结实的工具"，而不是主体。必要条件和充分条件之间，我还没填上。

整场对话最后落到的三句话

循环让它能自己走；验证让它走对方向；承担让它值得被信任。
前两个已经拿到了。第三个，浏览器智能体永远拿不到——因为它不会疼。
